## Shared community defaults

GitHub uses this public `.github` repository to supply contribution, conduct, support, security, and issue/PR templates to organization repositories that do not provide their own. Project-specific files take precedence.

The organization profile lives in [`profile/README.md`](profile/README.md). Brand source files and share images live in [`assets/`](assets/README.md). The [maintenance guide](MAINTAINING.md) keeps this setup easy to update.
