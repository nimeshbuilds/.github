# Nimesh Builds brand assets

The brand uses a modular **N**, a small amber spark, and a dark background. Blue and teal suggest the pieces of a system coming together; amber marks the act of building.

| Asset | Purpose |
| --- | --- |
| `banner.svg` / `banner.png` | Organization profile header, 1280 × 400 |
| `social-preview.svg` / `social-preview.png` | Repository link preview, 1280 × 640 |

The SVGs are the editable source. PNG exports are committed so the profile does not need a build service or third-party image host. To update a PNG, edit its SVG and export at its declared dimensions using a vector editor or an SVG renderer such as Sharp. Keep the social preview under 1 MB.

Palette: background `#0C121C`, text `#F2F6FC`, blue `#2558EE`, teal `#42D5B3`, amber `#FFC342`.

Keep text legible at small sizes, include descriptive alternative text, and preserve the name and mark without implying endorsement of unrelated projects. The existing organization avatar remains the primary profile icon.
