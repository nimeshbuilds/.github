# Security policy

## Report privately

If the affected Nimesh Builds repository offers **Security → Report a vulnerability**, use that private reporting channel. Otherwise, use the [central private report form](https://github.com/nimeshbuilds/.github/security/advisories/new) and name the affected repository.

Do not open a public issue or discussion containing exploit details, credentials, or private cluster data. Only investigate systems you own or have permission to test.

Include the affected project and version, a sanitized reproduction, the potential impact, and any mitigation you have identified. The maintainer can discuss reproduction and disclosure through the private report.

## Current support

This community repository contains documentation and templates. ClusterReplica has no released software or supported version matrix yet. Future software repositories will document their supported versions and may provide a more specific policy.

Maintainers will review reports and coordinate remediation and disclosure where applicable. No fixed response or resolution time is promised.
