# Getting help

Use [Nimesh Builds Discussions](https://github.com/orgs/nimeshbuilds/discussions) for questions, setup help, use cases, and early ideas.

- **A reproducible bug:** open an issue in the affected repository, with the version, expected behavior, actual behavior, and minimal reproduction.
- **A docs or profile correction:** open an issue or pull request in [this community repository](https://github.com/nimeshbuilds/.github).
- **A security vulnerability:** follow [SECURITY.md](SECURITY.md).
- **A conduct concern:** follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Do not publish passwords, tokens, kubeconfigs, customer data, or full production configuration. Use sanitized examples.

ClusterReplica is currently a proposed project. There is no released installation to support. Design feedback and real integration-testing use cases are welcome. Support is community-based, without guaranteed response times.
